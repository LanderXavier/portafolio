# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + Vite + Tailwind (same as previous portfolio), published on GitHub Pages,
replacing the previous site on the same URL.

## Users

Technical recruiters and hiring managers. They scan fast (under a minute), look for
proof of real shipped work, then decide whether to make contact. No other audience
is prioritized; freelance clients are explicitly out of scope for this version.

## Product Purpose

Personal portfolio of Lander Lliguicota, AI & Automation Engineer (Quito, Ecuador),
to get hired. Success means a recruiter reaches the contact section and writes an email.

## Positioning

Freelance client systems actually deployed and running — an on-premise clinic CRM on
n8n/Docker to avoid hosting costs, a sales bot with idempotent PostgreSQL storage —
plus RAG depth (pure LangChain, TITEC 2026 paper co-author) and an IoT award
(3rd place, Comufest 2026). A neighboring portfolio cannot truthfully copy deployed
client work; this one must show systems in production, not prototypes.

## Operating Context

Single-page site, one scroll: hero, about, expertise, projects, skills, experience,
certifications, contact. English. Viewed mostly on desktop by recruiters, mobile must
still read cleanly. Motion exists only if it never slows scanning.

## Capabilities and Constraints

- English copy; reuse all current content: 6 projects, photos, certificates, experience.
- Contact paths: email (landerx345@gmail.com), GitHub (LanderXavier), LinkedIn.
- Binding constraint volunteered by the owner: must not look AI-made — no dark-neon
  template aesthetic, no generic template copy, no gratuitous library animation.
- Real project gallery images and the GitHub link for bot_ventas carry over.

## Brand Commitments

Name: Lander Lliguicota. Title: AI & Automation Engineer. Base: Quito, Ecuador.
No logo, no palette, no typeface is carried over — the visual world is replaced.

## Evidence on Hand

- Project screenshots in the current repo (`src/assets/` subfolders: dental, rag,
  ventas, moodmirror, farm, kichwa) plus hero photo (`src/assets/hero.png`).
- Live repo link: `https://github.com/LanderXavier/bot_ventas`.
- Certificates: Scrum Foundation, Samsung Innovation Campus (assets in `src/assets/cert/`).
- Absent and must not be fabricated: testimonials, client names, metrics without a source.

## Product Principles

1. Proof before claims: every statement points at a shipped system, a repo, or a document.
2. Scan in under a minute: the hiring decision must survive a fast scroll.
3. One reader, one action: everything serves the recruiter reaching contact.
4. Restraint is the aesthetic: if an element does not help the decision, it goes.
