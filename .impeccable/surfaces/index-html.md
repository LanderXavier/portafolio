# Surface brief — portfolio 2.0 home

Scope: single-page portfolio home (hero through contact), new scaffold in portafolio-2.0.
Visitor mode: Experience — the work itself leads; the interface recedes.

Audience, job, action: technical recruiters scanning fast; job is deciding to make
contact; action is the mailto contact CTA in the signature block.
Proof and content: all current English content reused (6 projects, photos, certs,
experience); sections may be cut or merged. Every system ships as a signed record
with its seal (Deployed / Paper / Award / Shipped); every image carries a source
line. No testimonials exist; none are invented.
Constraints: must not read AI-made (no dark-neon, no template copy shells, no
gratuitous motion); mobile must read cleanly; one authored motion moment only
(the seal press), everything else instant.

Chosen direction: acta de entrega / commissioning report (grounded candidate 3,
roll-assigned and user-confirmed after discarding the pipeline board). Memorable
moment: each deployed system arrives as a stamped receiving record, and the page
closes with a signature block instead of a contact card.
Build notes carried over: every project legible from a one-line label; evidence in
measured ruled rows; seals mark only real proof, never decoration.
Unresolved: deploy target (replace Pages site vs separate repo/URL); display/mono
faces load from Google Fonts at runtime.

## Direction contract

THESIS: A receiving file, not a gallery. The page is the commissioning dossier of
one engineer: each system delivered is an acta with scope, stack, evidence, and a
red seal, and the scroll is the file working toward signature. It refuses the dark
hero plus project-cards template and refuses corporate sobriety without character;
paper, ink, and a utilitarian red carry the whole page.

OWN-WORLD: Warm paper ground flooded edge to edge, ink text, one stamp-red accent
plus warm ledger grays; hairline rules and clause numerals (I–V) as the only
structure; workhorse grotesk headlines with mono form data (folios, dates, stacks);
an ID-style subject block with photo, statement, and three background signals; acta
records with rotated seal stamps; a signature block closing with the contact action.
No glow, no gradients, no shadows, no entrance animation.

STORY: The visitor understands within seconds that this engineer delivers systems
that clients signed for, believes it through sealed records with captioned evidence,
reads background, record, and credentials as clauses, and signs off by writing an email.

FIRST VIEWPORT: Masthead with file title, folio, date, and place; subject block with
photo, name and title, one-line statement, three background signals, and the contact
action plus GitHub and LinkedIn. Clause I begins below with scope checks, not biography.

FORM: Commissioning report / acta de entrega; ordered position 3 of 7 grounded
candidates; seed key e29767cf (roll-assigned, user-confirmed).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
