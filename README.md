# Lander Lliguicota — Portfolio 2.0

Personal portfolio, designed as a commissioning dossier ("receiving file"):
background, sealed delivery records, work history with credentials, signature block.

Built with React + Vite + Tailwind CSS v4. No animation libraries, no dark-neon
template looks: paper, ink, one stamp red.

```bash
npm install
npm run dev
```

Production build (`dist/`, deployed to GitHub Pages):

```bash
npm run build
```
